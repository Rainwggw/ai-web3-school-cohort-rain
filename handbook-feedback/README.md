# Handbook Feedback

This directory contains feedback and suggestions for the AI × Web3 School Handbook.

## How to Submit Feedback

Each feedback file should include:
1. **Handbook Page Link**: URL of the page with issue
2. **Problem Description**: What's unclear, outdated, or incorrect
3. **Suggested Improvement**: How it could be fixed
4. **Source**: Your reasoning or reference

## Feedback Template

```markdown
# Feedback: [Brief Title]

## Handbook Page
- URL: https://aiweb3.school/zh/handbook/...

## Issue Type
- [ ] Concept unclear
- [ ] Outdated information
- [ ] Typo / Error
- [ ] Missing content
- [ ] Structure suggestion

## Description


## Suggested Improvement


## Source / Reference

```

## Naming Convention

- `YYYY-MM-DD-brief-topic.md`
- Example: `2026-05-19-llm-typo-fix.md`
